# Counting DNA Nucleotides

**Rosalind Problem ID:** DNA

**Track:** Bioinformatics Stronghold

**Language:** Python

## Problem

Given a DNA sequence, count the number of occurrences of
A, C, G, and T.

## Approach

A dictionary is used to store the count of each nucleotide.
The DNA sequence is traversed once and the corresponding
counter is incremented for each nucleotide.

## Complexity

- Time complexity: O(n)
- Auxiliary space complexity: O(1)
